# Firmware

This folder contains ESP32 firmware variants for the R.A.M.S prototype node.

## Variants

- esp32-max6675-flask-api: sends MAX6675 temperature readings to the Flask backend.
- esp32-max6675-supabase: sends MAX6675 temperature readings to Supabase REST API for prototype testing.

Both sketches contain placeholder credentials. Replace WiFi, API URL, and API key values locally before flashing.
